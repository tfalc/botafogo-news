# Escudos nas tabelas — política do projeto

## Regra

**Não incorporar escudos oficiais** de clubes brasileiros (nem CBF/CONMEBOL) no front-end por enquanto.

O Portal Fogão é **informativo e sem monetização** hoje — isso baixa a prioridade de cobrança na prática, mas a decisão do projeto é manter só nomes (e badges de iniciais próprios, se houver), até haver licença ou nova avaliação explícita.

## Por quê

- Marca e símbolos esportivos são protegidos (Lei 9.279/1996; Lei 9.615/1998 art. 87).
- Clubes têm enforcement ativo (notificações a fanpages, artesãos, produtos).
- “Está no Google / Wikimedia” **não** equivale a permissão de marca.

## O que usar no Portal Fogão

1. Nome completo do time (já usado).
2. Opcional: badge circular com **iniciais** (ex.: `BOT`, `FLA`) em estilo próprio preto/branco — asset original do projeto.
3. Destaque visual do Botafogo por CSS (linha destacada), sem escudo.

## O que não baixar para este repositório

- SVG/PNG de escudos oficiais
- “Kit de crest pack” de sites de terceiros
- Logos redistribuídos por APIs de odds/dados (salvo contrato explícito)
